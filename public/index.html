Watch Party

Salas para assistir filmes e séries ou compartilhar sua tela com outras pessoas. Entre com sua conta Discord para validar sua identidade.

Entrar com Discord

Comandos do bot Discord

  • /watch type:Movie name:Inception

    Cria uma sala para filme.

  • /watch type:Series name:Supernatural

    Cria uma sala para série e solicita temporada e episódio.

  • /screenshare

    Cria uma sala para compartilhamento de tela via WebRTC.

  • /status

    Lista as salas abertas no servidor.
